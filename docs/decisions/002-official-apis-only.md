# ADR-002: فقط API رسمی و صفحات عمومی مجاز

- **وضعیت:** پذیرفته (۲۰۲۶-۰۹-۲۵)

## زمینه
بیشترین اطلاعات کسب‌وکارهای ایرانی در Google Maps، Instagram و Facebook است. این سرویس‌ها اسکرپینگ را در قوانینشان ممنوع کرده‌اند، به‌صورت فعال بلاک می‌کنند و (در مورد Meta) سابقه‌ی شکایت حقوقی دارند.

## تصمیم
- داده فقط از API رسمی یا صفحات عمومی‌ای گرفته می‌شود که ToS و `robots.txt` آن‌ها اجازه می‌دهند.
- Instagram و Facebook **به‌صورت غیرمستقیم** پوشش داده می‌شوند: از داده‌ی بازی که Meta در Overture Maps منتشر کرده و لینک‌هایی که در OSM و وب‌سایت‌های کسب‌وکارها ثبت شده ([ADR-005](005-no-account-sources-first.md)). به‌صورت اختیاری، از طریق Brave و Business Discovery.
- هر سورس قبل از پیاده‌سازی در `docs/sources/` مستند و بررسی می‌شود.

## گزینه‌ی ردشده: اسکرپینگ
- ریسک حقوقی برای پروژه و صاحبش
- نگهداری سنگین: تغییر مداوم HTML، بلاک شدن IP، CAPTCHA
- هزینه‌ی پراکسی (با تصمیم ADR-003 در تضاد است)

## پیامدها
- پوشش اینستاگرام و فیس‌بوک به ایندکس موتور جست‌وجو وابسته است و کامل نیست
- برای جبران این کمبود، فرم ثبت کاربران و دایرکتوری‌های ایرانی اهمیت بیشتری پیدا می‌کنند

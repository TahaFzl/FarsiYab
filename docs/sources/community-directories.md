# دایرکتوری‌های ایرانی

- **شناسه در کد:** `directory:<slug>` (هر دایرکتوری یک شناسه‌ی جدا دارد)
- **وضعیت:** 🔍 **کاندیدها شناسایی شده‌اند؛ ToS هیچ‌کدام هنوز بررسی نشده است**
- **حساب کاربری:** ❌ لازم نیست (صفحات عمومی)
- **نوع دسترسی:** به ترتیب اولویت: ۱) **همکاری مستقیم** (فایل یا API با اجازه‌ی صاحب سایت) ۲) کراول صفحات عمومی در صورتی که ToS و `robots.txt` اجازه بدهند ۳) فقط لینک

## چرا مهم است
کسب‌وکاری که خودش را در یک دایرکتوری ایرانی ثبت کرده، **خودش اعلام کرده که ایرانی است**. این قوی‌ترین و اخلاقی‌ترین مدرک ممکن است (`listed_in_iranian_directory`، وزن ۰٫۶).

## ⚠️ نکات حقوقی مخصوص دایرکتوری‌ها
- **اطلاعات واقعی** مثل نام، آدرس و تلفن معمولاً مشمول کپی‌رایت نیستند، ولی **متن توضیحات، عکس‌ها و نظرات** هستند. **فقط اطلاعات واقعی و لینک صفحه برداشته می‌شود.**
- **در اتحادیه‌ی اروپا و انگلستان «حق پایگاه داده» (sui generis database right)** وجود دارد. برداشتن «بخش قابل‌توجهی» از یک دیتابیس بدون اجازه ممنوع است، حتی اگر فقط اطلاعات واقعی باشد. **برای دایرکتوری‌های اروپایی (مثل parsian.eu و iranilink) فقط همکاری مستقیم یا لینک مجاز است.**
- اکثر این دایرکتوری‌ها کسب‌وکارهای کوچکی هستند که از ترافیک سود می‌برند. **پیشنهاد همکاری** (لینک برگشتی و ذکر منبع در ازای دسترسی به داده) معمولاً از کراول بهتر است، هم از نظر قانونی و هم از نظر رابطه با جامعه.
- بسیاری از این سایت‌ها از هم کپی می‌کنند. Entity Resolver تکراری‌ها را ادغام می‌کند و **نشانه‌ی `listed_in_iranian_directory` فقط یک بار حساب می‌شود**.

## چک‌لیست بررسی هر دایرکتوری

| مورد | توضیح |
|---|---|
| URL | |
| شهرها و کشورها | |
| تعداد تقریبی کسب‌وکارها | |
| به‌روز بودن | تاریخ آخرین آگهی یا به‌روزرسانی |

| ToS | جمع‌آوری خودکار ممنوع است؟ |

| تصمیم | 🤝 همکاری / ✅ کراول / 🔗 فقط لینک / ❌ رد (با دلیل) |

## قواعد کراول (فقط در صورت تأیید)
- User-Agent شفاف (`FarsiYabBot`) و رعایت `robots.txt` و `Crawl-delay`
- استفاده از `sitemap.xml` در صورت وجود (به‌جای دنبال کردن همه‌ی لینک‌ها)
- حداکثر ۱ درخواست در ثانیه برای هر دامنه و فقط یک بار در هفته
- هر دایرکتوری یک parser جداگانه در `adapters/directories/<slug>.py` با تست روی HTML ذخیره‌شده دارد

## لینک به کاربر
لینک صفحه‌ی همان کسب‌وکار در دایرکتوری. در حالت «فقط لینک»، لینک صفحه‌ی شهر و دسته.

## ذکر منبع
نام دایرکتوری با لینک؛ در صورت همکاری، طبق توافق

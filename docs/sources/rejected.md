# سورس‌های بررسی‌شده و ردشده

این فایل وجود دارد تا دلیل کنار گذاشتن هر سورس ثبت شود و دوباره بررسی تکراری انجام نشود. اگر شرایط یک سورس (مثلاً قیمتش) عوض شد، می‌تواند دوباره بررسی شود.

| سورس | دلیل رد | تاریخ بررسی |
|---|---|---|
| **Yelp Fusion / Places API** | دیگر رایگان نیست: فقط ۳۰ روز آزمایشی (حداکثر ۵٬۰۰۰ درخواست) که **استفاده‌ی تجاری در آن ممنوع است**. بعد از آن حداقل حدود ۸ دلار برای هر ۱٬۰۰۰ درخواست. در ضمن اسکرپینگ Yelp ممنوع است. | ۲۰۲۶-۰۹ |
| **Foursquare Places API** | از ژوئن ۲۰۲۶ فقط ۵۰۰ درخواست رایگان Pro در ماه دارد؛ endpoint های Premium رایگان نیستند. با حجم ما صرفه ندارد. اگر پوشش بیشتری لازم شد، دوباره بررسی شود. | ۲۰۲۶-۰۹ |
| **Google Custom Search JSON API** | برای مشتریان جدید بسته است و ۱ ژانویه‌ی ۲۰۲۷ خاموش می‌شود. | ۲۰۲۶-۰۹ |
| **اسکرپینگ Google Maps / Google Search** | خلاف ToS گوگل است، بلاک و CAPTCHA می‌شود. جایگزین: لینک Maps URLs (بدون کلید) و Places API (اختیاری). | ۲۰۲۶-۰۹ |
| **اسکرپینگ Instagram / Facebook** | خلاف ToS است و Meta سابقه‌ی شکایت حقوقی علیه اسکرپرها دارد. جایگزین: داده‌ی باز Meta در Overture Maps و لینک‌های ثبت‌شده در OSM و وب‌سایت‌ها. | ۲۰۲۶-۰۹ |
| **Facebook Page Public Metadata Access** | نیاز به App Review و Business Verification سخت‌گیرانه دارد؛ برای MVP ارزش ندارد. در صورت رشد پروژه دوباره بررسی شود. | ۲۰۲۶-۰۹ |
| **گروه‌های فیس‌بوک / تلگرام خصوصی** | محتوای خصوصی است و دسترسی خودکار به آن مجاز نیست. | ۲۰۲۶-۰۹ |
| **LinkedIn** | ToS اسکرپینگ را ممنوع کرده و API عمومی برای جست‌وجوی شرکت‌ها ندارد. ضمناً بیشتر پروفایل‌ها شخصی هستند. | ۲۰۲۶-۰۹ |
| **سرویس‌های واسط اسکرپینگ (Apify، SerpAPI و ...)** | پولی هستند و در عمل همان اسکرپینگ را انجام می‌دهند؛ مسئولیت نقض ToS از بین نمی‌رود. | ۲۰۲۶-۰۹ |
| **DuckDuckGo** | API رسمی جست‌وجوی وب ندارد؛ Instant Answer API نتیجه‌ی وب برنمی‌گرداند. اسکرپینگ هم طبق ToS ممنوع است. | ۲۰۲۶-۰۹ |
| **Foursquare OS Places (دیتاست باز)** | رایگان و باز است، ولی از اکتبر ۲۰۲۵ دانلودش نیاز به ثبت‌نام (Hugging Face یا پورتال Foursquare) دارد. در ضمن داده‌ی Foursquare **از قبل داخل Overture** هست. | ۲۰۲۶-۰۹ |
| **NPPES NPI Registry (آمریکا)** | بدون کلید و باز است، ولی **فیلد زبان ندارد**. تنها نشانه‌ی قابل استفاده نام شخص پزشک است که طبق [04](../04-iranian-detection.md) و [07](../07-legal-and-privacy.md) به‌تنهایی کافی نیست. ممکن است بعداً فقط برای **تأیید** آدرس و تخصص پزشکی که از سورس دیگری پیدا شده استفاده شود. | ۲۰۲۶-۰۹ |
| **API غیررسمی Arztsuche 116117** | endpoint `/api/data` session مرورگر می‌خواهد و مستند نیست. پروژه‌های متن‌باز به دلیل نگرانی حقوقی متوقفش کرده‌اند. جایگزین: لینک جست‌وجوی رسمی. | ۲۰۲۶-۰۹ |
| **Yelp Open Dataset** | فقط برای استفاده‌ی آموزشی و پژوهشی است و شهرهای محدودی دارد. | ۲۰۲۶-۰۹ |
| **REALTOR.ca / Zillow و سایت‌های املاک** | فیلتر زبان دارند، ولی ToS آن‌ها دسترسی خودکار را ممنوع کرده است. جایگزین: لینک. | ۲۰۲۶-۰۹ |
| **Kijiji / Craigslist / Divar خارج** | آگهی‌ها اغلب شخصی هستند و ToS اسکرپینگ را ممنوع کرده است. | ۲۰۲۶-۰۹ |
| **Bluesky / Mastodon** | API عمومی بدون حساب دارند، ولی کسب‌وکارهای ایرانی محلی عملاً در آن‌ها حضور ندارند. ارزش کمی دارند. | ۲۰۲۶-۰۹ |
| **Apple Maps / Bing Maps / HERE / TomTom (API)** | همه کلید یا حساب می‌خواهند. داده‌ی Microsoft از قبل داخل Overture هست. برای Apple فقط لینک ([link-only.md](link-only.md)). | ۲۰۲۶-۰۹ |
| **SearXNG (میزبانی شخصی)** | رایگان است، ولی موتورهای دیگر را اسکرپ می‌کند. | ۲۰۲۶-۰۹ |

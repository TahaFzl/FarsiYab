# ۱. نیازمندی‌ها

شناسه‌ها (مثل FR-3) برای ارجاع در کد و تسک‌ها استفاده می‌شوند.

## نیازمندی‌های کارکردی

### جست‌وجو

| شناسه | شرح | فاز |
|---|---|---|
| FR-1 | کاربر کشور را از یک لیست قابل جست‌وجو انتخاب می‌کند | MVP |
| FR-2 | کاربر شهر را انتخاب می‌کند؛ لیست شهرها بر اساس کشور فیلتر می‌شود و پیشنهاد خودکار دارد | MVP |
| FR-3 | کاربر یک یا چند دسته را انتخاب می‌کند (چندانتخابی) | MVP |
| FR-4 | با زدن «جست‌وجو»، نتایج موجود در ایندکس در کمتر از ۱ ثانیه نمایش داده می‌شوند | MVP |
| FR-5 | اگر نتایج ایندکس کم یا قدیمی باشند، جست‌وجوی لایو در پس‌زمینه شروع می‌شود و نتایج جدید به‌صورت تدریجی به صفحه اضافه می‌شوند | MVP |
| FR-6 | کاربر نتایج را بر اساس اطمینان، فاصله یا نام مرتب می‌کند | MVP |
| FR-7 | فیلتر نتایج بر اساس سورس و حداقل میزان اطمینان | فاز ۲ |
| FR-8 | نمایش نتایج روی نقشه (OpenStreetMap و Leaflet) | فاز ۲ |
| FR-9 | لینک جست‌وجو قابل اشتراک‌گذاری است (پارامترها در URL قرار می‌گیرند) | MVP |

### نمایش نتیجه

| شناسه | شرح | فاز |
|---|---|---|
| FR-10 | هر نتیجه نام (فارسی و لاتین در صورت وجود)، دسته، آدرس و راه‌های تماس را نشان می‌دهد | MVP |
| FR-11 | هر نتیجه **همه‌ی سورس‌هایی** را که در آن پیدا شده با لینک مستقیم نشان می‌دهد | MVP |
| FR-12 | هر نتیجه **مدارک ایرانی بودن** را نشان می‌دهد: نوع نشانه، متن کوتاه و لینک صفحه‌ای که نشانه در آن دیده شده | MVP |
| FR-13 | هر نتیجه یک برچسب اطمینان دارد (بالا، متوسط، پایین) | MVP |
| FR-14 | دکمه‌ی «گزارش اشتباه» (ایرانی نیست، بسته شده، اطلاعات غلط است) | MVP |
| FR-15 | تاریخ آخرین بررسی نتیجه نمایش داده می‌شود | MVP |

|---|---|---|
| FR-20 | فرم «کسب‌وکار ایرانی پیشنهاد بدهید» | فاز ۲ |
| FR-21 | صاحب کسب‌وکار درخواست حذف یا اصلاح می‌دهد | فاز ۲ |

### ادمین

| شناسه | شرح | فاز |
|---|---|---|
| FR-30 | پنل بررسی نتایج با اطمینان پایین و گزارش‌های کاربران | فاز ۲ |
| FR-31 | فعال یا غیرفعال کردن هر سورس و مشاهده‌ی سهمیه‌ی مصرف‌شده‌ی API ها | MVP (نسخه‌ی ساده) |
| FR-32 | اجرای دستی ایندکس برای یک شهر | MVP |

## نیازمندی‌های غیرکارکردی

| شناسه | شرح |
|---|---|
| NFR-1 | **هزینه‌ی صفر برای API ها**: هیچ سورسی نباید از سهمیه‌ی رایگانش بیشتر مصرف کند. سقف مصرف (hard cap) در کد پیاده‌سازی می‌شود، نه فقط در داشبورد سرویس |
| NFR-2 | **رعایت قوانین سورس‌ها**: فقط API رسمی یا صفحات عمومی‌ای که robots.txt و قوانین سایت اجازه می‌دهند. اسکرپینگ اینستاگرام، فیس‌بوک و Google Maps ممنوع است ([ADR-002](decisions/002-official-apis-only.md)) |
| NFR-3 | **دوزبانه و راست‌به‌چپ**: رابط کاربری کامل فارسی (RTL) و انگلیسی (LTR) |
| NFR-4 | پاسخ صفحه‌ی نتایج از ایندکس: p95 کمتر از ۱ ثانیه |
| NFR-5 | جست‌وجوی لایو حداکثر ۶۰ ثانیه طول می‌کشد؛ بعد از آن هر نتیجه‌ای که آماده شده نمایش داده می‌شود |
| NFR-6 | واکنش‌گرا و قابل استفاده روی موبایل |
| NFR-7 | هر سورس یک ماژول مستقل (آداپتر) است و خرابی یک سورس جست‌وجو را متوقف نمی‌کند |
| NFR-8 | حریم خصوصی: فقط اطلاعات عمومی کسب‌وکارها ذخیره می‌شود و برای افراد عادی پروفایل ساخته نمی‌شود ([07](07-legal-and-privacy.md)) |
| NFR-9 | SEO: صفحات شهر و دسته (مثلاً `/fa/canada/toronto/restaurant`) از سمت سرور رندر می‌شوند |

## محدوده‌ی MVP

- ۳ کشور و ۱۰ شهر پرجمعیت از نظر جمعیت ایرانی (لیست در [06](06-categories-and-locations.md))
- ۸ دسته‌ی اصلی
- سورس‌ها: OpenStreetMap، Google Places (در سهمیه‌ی رایگان)، جست‌وجوی وب برای کشف صفحات اینستاگرام و فیس‌بوک، دایرکتوری‌های ایرانی تأییدشده
- بدون حساب کاربری

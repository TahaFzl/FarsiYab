- [ ] آداپتر **Overture Maps** (اولین سورس، بدون حساب، تست‌شده)
- [ ] آداپتر OSM Overpass (بدون حساب)
- [ ] بررسی وب‌سایت کسب‌وکارها (مدرک و لینک اینستاگرام)
- [ ] لینک Google Maps URLs برای هر نتیجه

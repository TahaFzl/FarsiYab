# ADR-003: فقط سرویس‌های رایگان با سقف سخت مصرف

- **وضعیت:** پذیرفته (۲۰۲۶-۰۹-۲۵)

## زمینه
پروژه بودجه‌ای برای API های پولی ندارد. چند سرویس مهم (Google Places و Brave) سهمیه‌ی رایگان ماهانه دارند، ولی نیاز به ثبت کارت بانکی دارند و بعد از تمام شدن سهمیه هزینه می‌گیرند.

## تصمیم
- فقط سرویس‌های رایگان یا سهمیه‌ی رایگان سرویس‌ها استفاده می‌شوند.
- **Quota Guard** در کد، مصرف هر سورس را روی ۸۰٪ سهمیه‌ی رایگان محدود می‌کند و قبل از هر درخواست چک می‌شود.
- علاوه بر آن، در کنسول هر سرویس (در صورت امکان) سقف روزانه تنظیم می‌شود.
- مصرف در پنل ادمین نمایش داده می‌شود.

## پیامدها
- پوشش و تازگی داده محدود است: با سهمیه‌ی فعلی، هر (شهر، دسته) از Google حدوداً ماهی یک بار و از Brave حدوداً سه بار در ماه به‌روز می‌شود
- OSM (بدون سهمیه‌ی سخت) ستون اصلی داده است
- اگر پروژه رشد کرد و بودجه پیدا شد، فقط سقف‌های Quota Guard تغییر می‌کنند و معماری ثابت می‌ماند

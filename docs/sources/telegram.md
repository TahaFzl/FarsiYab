# تلگرام (کانال‌های عمومی)

- **شناسه در کد:** `telegram`
- **وضعیت:** ⏳ فاز ۵، فقط امکان‌سنجی
- **هزینه:** رایگان

## چرا
بخش بزرگی از کسب‌وکارهای کوچک ایرانی در خارج (خانگی، آرایشگری، شیرینی‌پزی و ...) به‌جای وب‌سایت کانال تلگرام دارند. کانال‌های «نیازمندی‌های ایرانیان {شهر}» هم رایج هستند.

## گزینه‌های دسترسی
| روش | وضعیت |
|---|---|
| پیش‌نمایش وب کانال‌های عمومی (`https://t.me/s/{channel}`) | صفحه‌ی عمومی است؛ ToS تلگرام و `robots.txt` باید بررسی شود |
| Telegram Bot API | ربات فقط پیام‌های کانال‌هایی را می‌بیند که عضو (ادمین) آن‌ها باشد؛ **برای کشف مناسب نیست** |
| MTProto (کلاینت کاربر، مثل Telethon) | با حساب کاربری واقعی کار می‌کند؛ برای جمع‌آوری انبوه ریسک بلاک شدن حساب دارد و با روح ADR-002 سازگار نیست |
| کشف از طریق جست‌وجوی وب (`site:t.me`) | مثل اینستاگرام؛ سازگار با روش فعلی |

## پیشنهاد اولیه
در فاز ۵، فقط **کشف** از طریق جست‌وجوی وب (`site:t.me "{city}" ایرانی`) و نمایش لینک کانال به‌عنوان سورس انجام شود. در مورد خواندن محتوای کانال‌ها بعد از بررسی حقوقی تصمیم گرفته می‌شود.

## ریسک‌ها
- محتوای کانال‌های نیازمندی‌ها اغلب آگهی‌های شخصی است (نه کسب‌وکار) و اطلاعات شخصی دارد → طبق [07](../07-legal-and-privacy.md) استفاده نمی‌شود
- خیلی از کانال‌ها غیرفعال یا قدیمی هستند

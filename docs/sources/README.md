# کاتالوگ سورس‌ها

هر سورسی که فارسی‌یاب از آن داده می‌گیرد اینجا مستند می‌شود. **هیچ سورسی بدون فایل مستند در این پوشه و بررسی ToS وارد کد نمی‌شود.**

> وضعیت قیمت‌ها، سهمیه‌ها و دسترسی‌ها و سهمیه‌ها مربوط به **سپتامبر ۲۰۲۶** است. این اعداد مرتب تغییر می‌کنند (مثلاً Brave در فوریه‌ی ۲۰۲۶ و Foursquare در ژوئن ۲۰۲۶ سهمیه‌ی رایگانشان را کم کردند). قبل از هر فاز دوباره بررسی شوند.

## خلاصه

طبق [ADR-005](../decisions/005-no-account-sources-first.md)، **MVP فقط با سورس‌هایی ساخته می‌شود که حساب کاربری، کلید یا کارت بانکی لازم ندارند.**

## درباره‌ی «گوگل‌پلی»

احتمالاً منظور از «گوگل پلی» **Google Maps** بوده است (Google Play فروشگاه اپلیکیشن است و کسب‌وکارهای محلی در آن ثبت نمی‌شوند). گرفتن داده‌ی Google Maps بدون حساب راه قانونی ندارد. ولی در MVP برای هر نتیجه لینک رایگان Google Maps URLs گذاشته می‌شود و Google Places API به‌صورت اختیاری در نظر گرفته شده است. اگر واقعاً منظور Google Play بوده (مثلاً پیدا کردن اپ‌های فارسی)، باید جداگانه بررسی شود.

## معیارهای پذیرش سورس جدید

یک سورس فقط وقتی اضافه می‌شود که **همه‌ی** شرط‌های زیر را داشته باشد:

1. دسترسی از طریق API رسمی یا صفحه‌ی عمومی‌ای که ToS و `robots.txt` آن اجازه‌ی دسترسی خودکار می‌دهند
2. هزینه‌ی صفر در حجم مورد نیاز ما، یا سهمیه‌ی رایگانی که با Quota Guard قابل کنترل باشد. **ترجیح با سورس‌هایی است که حساب کاربری نمی‌خواهند** ([ADR-005](../decisions/005-no-account-sources-first.md)).
3. داده‌ی آن حداقل یکی از این دو را بدهد: **کسب‌وکار کاندید جدید** یا **مدرک ایرانی بودن**
4. هر نتیجه یک **لینک عمومی** داشته باشد که بشود به کاربر نشان داد
5. شرایط ذخیره‌سازی داده روشن باشد

## الگوی مستند کردن سورس

هر فایل سورس این بخش‌ها را دارد:

```markdown
# <نام سورس>

- **شناسه در کد:** `source_id`
- **وضعیت:** MVP / فاز X / رد شده
- **نوع دسترسی:** API رسمی / صفحه‌ی عمومی / ...
- **مستندات رسمی:** لینک
- **قوانین استفاده (ToS):** لینک + خلاصه‌ی نکات مهم
- **هزینه و سهمیه:** ... (تاریخ بررسی)
- **حساب کاربری یا کلید:** لازم نیست / API key / OAuth

## چه داده‌ای می‌گیریم
## چطور کوئری می‌زنیم (با مثال)
## نشانه‌های ایرانی بودن که از این سورس درمی‌آید
## لینکی که به کاربر نشان داده می‌شود
## چه چیزی ذخیره می‌کنیم و تا کی
## محدودیت‌ها و ریسک‌ها
## ذکر منبع (attribution)
```
